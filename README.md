# Révisions Œnologie CEFOR

Site de révision pour l'examen d'œnologie (cours 1 à 5).

## Utilisation

Ouvrir `index.html` dans un navigateur — aucun serveur ni build nécessaire.
Les polices sont chargées depuis Google Fonts (connexion Internet requise pour l'affichage exact).

## Structure

- `index.html` — la page complète (contenu, styles, scripts)
- `slides/` — captures des diapositives de cours référencées par la page (`cX-NN.jpg` = cours X, diapo NN)
